# Self-Service Platform Engineering

## Overview

Doka Seca supports the [kro](https://github.com/thatdevopsfamily/kro) Kubernetes controller, enabling platform teams and
application owners to define and manage custom ResourceGraphDefinitions (RGDs) for advanced resource orchestration.

## What is kro?

kro is a Kubernetes controller that allows you to declaratively define resource graphs (RGDs) that describe how platform
and application resources are composed, deployed, and managed. RGDs enable flexible, reusable, and self-service
infrastructure patterns.

## Doka Seca Integration

- **GitOps-Ready**: RGDs and their instances can be managed via GitOps, using ArgoCD, for full auditability and repeatability.
- **Multi-Cluster**: RGDs can be applied to any cluster managed by Doka Seca, supporting both hub and spoke topologies.

## Use Cases

- Self-service application environments
- Complex deployment workflows
- Multi-resource orchestration
