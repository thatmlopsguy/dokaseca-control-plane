# Platform Engineering

## Overview

Doka Seca's platform engineering capabilities provide a comprehensive solution for building, deploying, and managing
modern applications on Kubernetes. With a focus on observability, automation, and developer experience, Doka Seca
empowers teams to deliver high-quality software efficiently.

## Observability Plane

Doka Seca includes a powerful observability plane that integrates seamlessly with Kubernetes, enabling you to monitor,
analyze, and optimize your applications and infrastructure. The plane consists of:

- **Victoria Metrics**: A high-performance time-series database for storing and querying metrics.
- **Victoria Logs**: A scalable log management solution for collecting and analyzing logs.
- **Tempo**: A distributed tracing system for understanding application performance and dependencies.
- **Grafana**: A leading open-source platform for visualizing and analyzing metrics, logs, and traces.
- **Headlamp**: A lightweight Kubernetes web UI for cluster browsing and basic workload management.
- **Alertmanager**: A powerful alerting system for managing and routing alerts based on your observability data.

## Security Plane

Doka Seca's security plane provides robust authentication, authorization, and access control mechanisms to protect your
Kubernetes environment. With support for role-based access control (RBAC), integration with external identity providers,
and fine-grained permissions, Doka Seca ensures that your cluster remains secure while enabling teams to collaborate effectively.
