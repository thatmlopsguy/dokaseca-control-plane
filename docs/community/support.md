# Support

Welcome to Doka Seca! We're here to help you get the most out of the project.

## Getting Help

There are several ways to get help with Doka Seca, listed in order of recommendation:

### 1. Documentation

Start with our [documentation](https://github.com/thatmlopsguy/dokaseca-control-plane#readme) which includes:

- Getting started guides
- Troubleshooting guides
- Best practices

Most common questions are answered in the docs.

### 2. GitHub Discussions

For questions, ideas, and community discussions, use [GitHub Discussions](https://github.com/thatmlopsguy/dokaseca-control-plane/discussions).

**Best for:**

- How-to questions
- Feature discussions
- Sharing use cases
- Community Q&A

## Reporting Bugs

**Please use GitHub Issues ONLY for bug reports and feature requests.**

Before creating a new issue:

1. Check existing issues to avoid duplicates
2. Review the [troubleshooting guide](https://github.com/thatmlopsguy/dokaseca-control-plane#readme/troubleshooting)
3. Gather relevant information (logs, versions, reproduction steps)

[Report a bug](https://github.com/thatmlopsguy/dokaseca-control-plane/issues/new?template=bug_report.md)

## What NOT to Report as Issues

Please **do not** use GitHub Issues for:

- ❌ General questions (use Discussions)
- ❌ Support requests (use Discussions)
- ❌ How-to questions (check documentation first)

Issues that don't follow this guideline may be closed and redirected to the appropriate channel.

## Response Time Expectations

This project is maintained by 1 maintainer(s) and we rely on community contributions and volunteer time.

**Response times vary based on:**

- Severity and impact of the issue
- Maintainer availability
- Community engagement

**Typical response times:**

- Critical bugs: best effort
- Feature requests: best effort
- Questions: best effort

Please be patient and respectful. This is an open-source project, and responses depend on volunteer time.

## Commercial Support

Professional support is not currently offered for Doka Seca. However, we encourage users to seek help through the community channels mentioned above.

## Security Vulnerabilities

**Do not report security vulnerabilities through public GitHub issues.**

Please follow our [Security Policy](https://github.com/thatmlopsguy/dokaseca-control-plane/security/policy) for responsible disclosure.

## Contributing

If you'd like to contribute to Doka Seca, please read our [Contributing Guide](https://github.com/thatmlopsguy/dokaseca-control-plane/blob/main/CONTRIBUTING.md).

We welcome:

- Bug fixes
- Feature implementations
- Documentation improvements
- Test coverage
- Community support

Our community follows the [Code of Conduct](https://github.com/thatmlopsguy/dokaseca-control-plane/blob/main/CODE_OF_CONDUCT.md). By participating, you agree to uphold a welcoming and inclusive environment for everyone.
