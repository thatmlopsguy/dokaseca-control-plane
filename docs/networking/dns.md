# DNS

Doka Seca's Kubernetes cluster uses CoreDNS as the default DNS provider. CoreDNS is a flexible and extensible DNS server that can be used to provide DNS services for Kubernetes clusters. It is designed to be fast, scalable, and easy to use.

## External DNS

External DNS is a Kubernetes add-on that automatically manages DNS records for Kubernetes resources. It allows you to create and manage DNS records for services, ingresses, and other Kubernetes resources without having to manually update your DNS provider.
