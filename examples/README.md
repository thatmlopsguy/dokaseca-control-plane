# Kubernetes Examples

This directory contains examples of Kubernetes resources that can be used to test and demonstrate the functionality of the Kubernetes cluster.

Examples include:

- external-secrets: An example of using External Secrets to manage secrets in Kubernetes.
- crossplane: An example of using Crossplane to manage cloud resources from Kubernetes.
